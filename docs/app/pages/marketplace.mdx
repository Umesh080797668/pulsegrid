# Marketplace

The Marketplace hosts connector integrations, templates, and published flows that teams can install into workspaces.

## Publishing Connectors

- Authors submit connector metadata (icon, name, actions, auth type) which is reviewed before publishing.
- Published connectors expose a manifest used by the UI to render configuration screens.

## Templates

- Templates are flow definitions that users can import to get started quickly (e.g., "Shopify → Slack order alerts").

## Governance

- Marketplace items have visibility and approval metadata; admins can approve or remove items.
